# Reference Validation

Citation integrity protocol for the charter and registers, carried over from the practice established in [`global-flood-hydrotectonic-model`](https://github.com/jdlongmire/global-flood-hydrotectonic-model)'s `reference_validation_protocol/`.

## Standard

Primary sources are located and quoted directly wherever access is feasible. Secondary characterization is never cited as primary. Where a primary is reached through a secondary, the citation says so ("as cited in").

Confidence is labelled:

| Label | Meaning |
|---|---|
| `HIGH` | Verified primary, direct quotation or direct reading |
| `MEDIUM` | Secondary with page numbers, appears reliable |
| `LOW` | Paraphrase without page numbers, or tertiary |
| `UNCERTAIN` | Cannot determine whether the claim originates with the primary |

Where secondaries conflict, the divergence is reported rather than arbitrated.
